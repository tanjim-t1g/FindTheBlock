Custom Lobby Setup

How to connect FindTheBlock to an existing hub, spawn, or custom lobby build.

If you already have a custom-built spawn castle, waiting arena, or manage worlds using Multiverse-Core, you do not have to use the default bedrock void platform. You can easily point FindTheBlock to any world and spawn location on your server.

How to Change the Lobby World

  1. Open plugins/FindTheBlock/config.yml in your text editor.
  2. Find the lobby section near the middle of the file.
  3. Set use-custom-world: true. This tells the plugin not to create its internal void world.
  4. Set world-name to your target world folder name (e.g. "hub", "spawn", or "world").
  5. Configure the exact coordinates where players should spawn when they join or finish a match:
    config.yml 
    lobby:
  use-custom-world: true    # Enable custom world binding
  world-name: "hub"         # Name of your world folder
  spawn-point:
    x: 100.5
    y: 72.0
    z: -250.5
    yaw: 180.0
    pitch: 0.0
  enforce-lobby-protections: true   # Keep PVP/hunger disabled in this lobby
  6. Save the file and run /ftb reload in-game or from your server console.

Multiverse & Multi-World Managers

If your server uses Multiverse-Core or HyperVerse:

  • Ensure your lobby world is loaded by Multiverse before players join.
  • If you use WorldGuard regions in your custom hub, you can set enforce-lobby-protections: false in config.yml so that your existing WorldGuard flags control building and PVP permissions instead of FindTheBlock.

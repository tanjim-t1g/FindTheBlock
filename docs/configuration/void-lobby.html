Void Lobby Generation

How FindTheBlock creates an isolated void world and safe bedrock platform out of the box.

Many servers do not want to install bulky third-party world management plugins just to have an empty lobby dimension. FindTheBlock includes an internal custom void chunk generator (VoidChunkGenerator.java) that builds and maintains a dedicated lobby world automatically.

The 100x100 Bedrock Platform

When the plugin boots for the first time:

  • It generates an empty void dimension named lobby.
  • At elevation Y: 100, it constructs a smooth 100x100 bedrock square spanning from X: -50 to X: 50 and Z: -50 to Z: 50.
  • The default player spawn point is centered at X: 0.5, Y: 101.0, Z: 0.5 facing south.

The Y=90 Void Safety Boundary

If a player jumps, walks, or gets pushed off the bedrock platform, ProtectionListener.java catches them as soon as their Y-level drops below Y: 90:

  • Their downward velocity is stopped.
  • They are instantly teleported back to the center spawn point (0.5, 101.0, 0.5).
  • They take zero fall or void damage.

Automatic Protections

Inside the lobby world, the following rules are enforced 24/7 without requiring plugins like WorldGuard:

Action Default Status
Block Breaking / Placing Blocked for all non-operators (bypassable with findtheblock.bypass)
PVP & Player Damage Completely disabled
Hunger Depletion Disabled (food level locked at 20)
Mob Spawning Cancelled for both hostile and passive mobs
Weather & Time Locked to clear weather and permanent daylight

Configuring the Platform

config.yml 
lobby:
  use-custom-world: false   # Set to true if using an existing server hub
  world-name: "lobby"       # Dedicated void world folder name
  platform:
    material: BEDROCK       # Material used for the platform floor
    size: 100               # Width and length of platform in blocks
    y-level: 100            # Y coordinate of the platform surface
    void-threshold: 90      # Y level that triggers instant teleport back up

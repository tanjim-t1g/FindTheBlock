Difficulty Tiers

Configure item pools, control round duration, and help players with the in-game recipe guide.

FindTheBlock includes three built-in difficulty tiers: EASY, NORMAL, and HARD. Each tier defines a pool of items that the roulette selector picks from at the beginning of each round.

Tier Overview

Tier Sample Items Focus & Style
EASY (1 pt) Diamond Ore, Emerald Ore, Amethyst Block, Dripstone, Slime Block, Sponge, Dead Corals Mining & straightforward exploration
NORMAL (3 pts) Ancient Debris, Crying Obsidian, Sea Lantern, Prismarine, Nylium, Resin Blocks, Sculk Sensors Biome travel, Silk Touch, Nether exploration
HARD (5 pts) Mob Heads, Heavy Core, Shulker Boxes, Netherite Block, Beacon, Ender Chest, Lodestone Rare loot, boss encounters, heavy resources

Starting a Match with a Specific Tier

Pass the tier as an argument, or choose it visually in the in-game Mode Selection GUI:

In-Game Chat 
/start easy
/start normal
/start hard

# Start for all lobby players (Admin only)
/ftb startall easy
/ftb startall normal
/ftb startall hard

If no tier is specified, the plugin uses the default-tier setting from config.yml.

Customizing Item Pools

You can add any vanilla block to the lists under targets in config.yml using standard Bukkit Material names:

config.yml 
targets:
  default-tier: "NORMAL"
  EASY:
    - "DIAMOND_ORE"
    - "EMERALD_ORE"
    - "AMETHYST_BLOCK"
    # ... See BLOCK_LIST.txt for complete listings
  NORMAL:
    - "ANCIENT_DEBRIS"
    - "CRYING_OBSIDIAN"
    - "RESIN_BLOCK"
    # ... See BLOCK_LIST.txt for complete listings
  HARD:
    - "DRAGON_HEAD"
    - "HEAVY_CORE"
    - "SHULKER_BOX"
    # ... See BLOCK_LIST.txt for complete listings

In-Game Recipe Guide (/recipe)

Not every player remembers complex vanilla crafting recipes (such as dispensers, daylight sensors, or pistons). During an active match, any participant can execute:

In-Game Chat 
/recipe

This opens a 9-slot crafting matrix GUI showing the exact layout of ingredients required to assemble the active target block, along with smelting instructions if the item requires a furnace.

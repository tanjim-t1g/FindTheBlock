Troubleshooting & FAQ

Answers to common questions and operational troubleshooting.

Can players enter the Nether and End?

Yes, players can enter the Nether! Every match generates a linked pair: the match Overworld (ftb_<id>) and match Nether (ftb_<id>_nether). When players light and step into a Nether portal, PortalListener.java translates coordinates between the two worlds with 1:8 scaling.

The End is disabled: Stronghold End portals do not generate an End dimension. Finding a Stronghold, gathering 12 Eyes of Ender, and fighting the Ender Dragon takes much longer than standard rush rounds, so matches remain focused on the Overworld and Nether.

Why are placeholders displaying as raw text?

If scoreboards or tablists display %findtheblock_target% instead of the actual item name:

  1. Verify that PlaceholderAPI is installed and enabled in your server's plugins/ folder.
  2. Check server startup logs to confirm FindTheBlock registered its expansion: 
    [FindTheBlock] Registered PlaceholderAPI expansion: %findtheblock_*%
  3. Run /papi reload in-game, followed by /ftb reload.

How are ties handled if two players get the block at the same time?

Bukkit events process sequentially on the primary server thread. The first player acquisition event to execute acquires an atomic state lock on GameManager#triggerWin(). The game state instantly switches to PODIUM, which prevents any subsequent pickups from triggering secondary wins.

How do I reset leaderboards and player stats?

Player career wins, games played, and records are stored in plugins/FindTheBlock/stats.yml. To reset the leaderboards completely:

  1. Stop the server (or run /ftb stop if a match is running).
  2. Delete or edit plugins/FindTheBlock/stats.yml.
  3. Restart your server or reload the plugin. A clean stats file will be created.

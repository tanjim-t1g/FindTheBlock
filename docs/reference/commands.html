Commands & Permissions

Complete reference of in-game commands, arguments, and permission nodes.

All in-game commands for players, parties, and administrators.

Command List

Command Permission Description
/party, /p findtheblock.use Opens Party Management if in a party, or Party Finder if solo.
/party finder findtheblock.use Opens the public Party Finder GUI to discover and join parties.
/party create [public|private] findtheblock.use Creates a new party (public by default).
/party invite <player> findtheblock.use Invites a player to join your party.
/party accept / /party deny findtheblock.use Accepts or declines a pending party invitation.
/party leave / /party disband findtheblock.use Leaves or disbands your current party.
/party start [tier] findtheblock.use Starts the 20-second ready check for your party members.
/start [tier] findtheblock.use Starts a 20-second party match ready-check (party leaders only).
/join findtheblock.use Allows a player who connected mid-match to join as a late racer.
/spectate, /spec findtheblock.use Enters an ongoing match as a spectator with flight and player tracker compass.
/leave findtheblock.use Leaves your active match or party and returns you to the lobby.
/recipe findtheblock.use Opens a GUI showing the recipe or acquisition guide for the active match target.
/menu, /selector findtheblock.use Opens the Match Selector and Party Hub GUI (or right-click lobby compass).
/top findtheblock.use Opens an interactive GUI leaderboard showing top podium winners.
/ftb startall [tier] findtheblock.admin Starts a match for all players currently waiting in the lobby world.
/ftb stop / /ftb stopall findtheblock.admin Aborts all matches immediately, returns all players to the lobby, and purges match worlds.
/ftb leaderboard [spawn/remove] findtheblock.admin Spawns or removes in-world floating hologram leaderboards.
/ftb reload findtheblock.admin Reloads config.yml and updates in-world leaderboards.

Permissions Reference

Permission Node Default Description
findtheblock.admin Operators Access to administrative commands (/ftb start, /ftb stop, /ftb reload).
findtheblock.use All players (true) Access to player commands (/party, /join, /spectate, /recipe, /menu, /top, /leave, /start).
findtheblock.bypass Operators Bypasses lobby block protection, allowing breaking and placing blocks in the lobby world.

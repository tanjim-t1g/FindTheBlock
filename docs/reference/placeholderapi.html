PlaceholderAPI & Leaderboards

Native placeholders for scoreboards, tablists, holograms, and leaderboards.

FindTheBlock includes a native expansion for PlaceholderAPI under the %findtheblock_*% prefix. No separate expansion download is needed.

Match Placeholders

Placeholder Type Description
%findtheblock_state% String Current match state (LOBBY, COUNTDOWN, ACTIVE, PODIUM, RESETTING).
%findtheblock_target% String Formatted display name of the target block (e.g. Piston or Oak Boat).
%findtheblock_target_raw% String Raw uppercase material enum name (e.g. PISTON).
%findtheblock_time_remaining% String Time left in the match formatted as MM:SS.
%findtheblock_time_elapsed% String Time elapsed since match start formatted as MM:SS.
%findtheblock_players_alive% Integer Number of active racers currently in the match world.

Personal Stats Placeholders

These placeholders query the viewing player's career statistics stored in stats.yml:

Placeholder Type Description
%findtheblock_wins% Integer Total matches won by the player.
%findtheblock_games_played% Integer Total rounds participated in.
%findtheblock_win_rate% String Win percentage formatted with one decimal place (e.g. 37.5%).
%findtheblock_fastest_win% String Personal fastest win duration formatted as MM:SS (or None).

Leaderboard Placeholders

Leaderboards rank the top 10 players on the server. Replace {rank} with an integer from 1 to 10:

Placeholder Type Description
%findtheblock_leaderboard_wins_{rank}_name% String Username of player holding that rank for total wins.
%findtheblock_leaderboard_wins_{rank}_score% Integer Win count of the player at that rank.
%findtheblock_leaderboard_time_{rank}_name% String Username holding that rank for fastest completion.
%findtheblock_leaderboard_time_{rank}_score% String Fastest completion time formatted as MM:SS.

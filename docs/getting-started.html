Quick Start Guide

Install the plugin and start your first match in 3 easy steps.

1. Requirements

  • Server: Paper 1.21.1+ (or Purpur).
  • Java: Java 21 LTS.
  • Optional: PlaceholderAPI if using scoreboards.

2. Installation

  1. Drop FindTheBlock-1.0.0.jar into your server's plugins/ folder.
  2. Restart your server.
  3. Done! The plugin creates its files in plugins/FindTheBlock/ automatically.

3. Play a Match

  1. Join the server. You will spawn on the safe bedrock platform in the void lobby.
  2. Give yourself admin rights with /op <your_name>.
  3. Start a match:
    Chat 
    /start normal
  4. The 10-second countdown begins, the roulette picks an item, and you are scattered into the world.
  5. Forgot how to craft the target item? Type /recipe to see the crafting table recipe.
  6. Collect or craft the item to win!

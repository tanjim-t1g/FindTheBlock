World Generation & Nether

How fresh Overworld and Nether worlds are generated in the background with zero server lag.

1. The World Factory

Instead of freezing the main server thread when a match starts, FindTheBlock generates worlds in the background:

  • Overworld + Nether: Every match creates two worlds: ftb_<id> and ftb_<id>_nether using the exact same random seed.
  • Chunk Pacing: Chunks are loaded at 30 chunks per second so your server stays at a locked 20.0 TPS.
  • Auto-Cleanup: When the round finishes, both worlds are deleted from disk automatically.

2. How Nether Portals Work

Nether portals work normally in every match:

  • Light an obsidian portal in the match Overworld → walk in → teleport to the match Nether at X / 8, Z / 8.
  • Walk through a portal in the match Nether → teleport back to the match Overworld at X * 8, Z * 8.

3. The End Dimension

The End dimension is supported on-demand:

  • If a player activates and jumps into an End Portal, a dedicated End world (ftb_<id>_the_end) is loaded for that match instance.
  • If no player enters the End, it is never loaded to save server RAM and CPU.
  • When the match ends, all dimensions (Overworld, Nether, and End) are wiped automatically.

Change Lobby World

How to use your own custom spawn, hub build, or multi-world lobby instead of the auto-generated void platform.

Configuration

Open plugins/FindTheBlock/config.yml and set your world name and disable the platform under the lobby section:

config.yml 
lobby:
  world-name: "hub"        # Exact name of your custom world folder
  platform:
    auto-generate: false   # Disable the auto-generated bedrock platform

  # Automatic void protection
  void-teleport: true
  void-teleport-blocks-above-damage: 2.0

Setup Steps

  1. Make sure your custom world folder is placed in your server directory and loaded.
  2. Open config.yml and set lobby.world-name to your world's exact name.
  3. Set lobby.platform.auto-generate: false so the 100x100 bedrock box is not built inside your world.
  4. Join the server, go to your custom lobby world, stand where you want players to spawn, and run /setworldspawn.
  5. Restart the server.

Automatic Lobby Features

When using a custom lobby world, FindTheBlock automatically manages the following protections:

  • World Spawn Integration: Players joining the lobby or returning from matches spawn at the world spawn point set by /setworldspawn.
  • Keep Inventory: keepInventory is automatically enforced on the lobby world. If a player dies, their items and XP are preserved with zero ground drops.
  • Void Fall Protection: If players slip off your lobby build into the void, they are caught 2 blocks before void damage starts and teleported back to the world spawn with fall distance reset to zero.
